# 💕 Will You Be My Valentine? 💕

A romantic, interactive Valentine's Day proposal website built with React, styled like the classic game show "Who Wants to Be a Millionaire?" - but with a romantic twist!

## ✨ Features

- 🎮 **Game Show Theme**: Styled like "Who Wants to Be a Millionaire" with lifelines and dramatic presentation
- 💖 **4 Romantic Options**: All answers are positive - no way to say no! (Because you're perfect together!)
- 🎨 **Beautiful Animations**: Smooth transitions, confetti effects, and heart rain
- 📱 **Mobile Friendly**: Fully responsive design that works on all devices
- 🎯 **Interactive Elements**: Clickable lifelines, animated buttons, and celebration effects
- 🌈 **Gradient Backgrounds**: Stunning animated gradients throughout

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone or download this repository
2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

### Building for Production

To create a production build:

```bash
npm run build
```

The build folder will contain the optimized production files ready to deploy!

## 🌐 Deploying to GitHub Pages

This project is already configured to deploy with `gh-pages`.

1. Update `homepage` in `package.json` to your GitHub username, for example:
   - `https://octocat.github.io/Qr-to-website`

2. Install dependencies:

```bash
npm install
```

3. Deploy:

```bash
npm run deploy
```

4. In GitHub repo settings:
   - **Settings → Pages → Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: **`gh-pages`** / root

## 💡 Customization

- Edit `src/App.js` to change the question or answers
- Modify colors in `src/App.css` (look for CSS variables and gradient colors)
- Adjust animations timing in the CSS files
- Add your own personal touches!
